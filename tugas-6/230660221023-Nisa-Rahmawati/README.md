## Deskripsi

Aplikasi Perpustakaan Kampus merupakan aplikasi sederhana untuk menampilkan katalog buku, melihat detail buku, dan mengajukan peminjaman melalui formulir. Aplikasi menggunakan named routes untuk mengatur perpindahan halaman, arguments untuk mengirim data, validasi formulir, dan SnackBar untuk memberikan umpan balik kepada pengguna.
