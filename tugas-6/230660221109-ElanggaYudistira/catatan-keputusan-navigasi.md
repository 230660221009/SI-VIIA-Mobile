# Catatan Keputusan Navigasi

| Keputusan | Pilihan | Alasan |
|---|---|---|
| Nama route | /login, /home, /transaction, /detail, /add | Route mengikuti kebutuhan layar aplikasi |
| Data antar layar | Map transaksi | Detail membutuhkan data dari daftar transaksi |
| Validator tiap field | Nama dan jumlah wajib diisi | Mencegah data kosong |
| Feedback aksi | SnackBar setelah simpan | Memberikan informasi proses berhasil |
