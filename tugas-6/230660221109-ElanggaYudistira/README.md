# MoneyTrack

Aplikasi pencatatan keuangan mahasiswa berbasis Flutter.

## Fitur
- Login
- Dashboard keuangan
- Daftar transaksi
- Detail transaksi
- Tambah transaksi

## Deklarasi AI
Saya menggunakan AI sebagai coding assistant untuk membantu memahami struktur navigasi Flutter, implementasi Form, dan penyusunan dokumentasi.

## Refleksi
Bagian yang paling sulit adalah menjaga konsistensi antara nama route, diagram navigasi, dan kode Flutter karena perubahan kecil pada satu bagian dapat menyebabkan navigasi tidak berjalan. Proses pengiriman data antar halaman juga membutuhkan perhatian karena harus memastikan tipe argument sesuai dengan data yang diterima. Dokumentasi keputusan membantu memastikan implementasi aplikasi tetap sesuai dengan kebutuhan awal.
