## Nama Aplikasi

**SiRuang Kampus**

## Deskripsi Halaman

SiRuang Kampus merupakan halaman aplikasi sederhana yang dibuat untuk membantu mahasiswa melihat ketersediaan ruangan di lingkungan kampus. Halaman ini menampilkan jumlah ruangan, jumlah ruangan yang tersedia, serta daftar ruangan yang dilengkapi dengan kategori dan status penggunaannya. Data yang digunakan masih berupa data statis di dalam kode dan tampilan dibuat menggunakan beberapa widget Flutter seperti Column, Row, Padding, Expanded, dan ListView.builder.

## Domain Sistem Informasi

**Peminjaman Ruang Kelas**

## Widget Layout yang Digunakan

Beberapa widget layout yang digunakan dalam halaman aplikasi ini adalah:

- **Column** untuk menyusun beberapa komponen secara vertikal.
- **Row** untuk menampilkan informasi jumlah ruangan secara berdampingan.
- **Padding** untuk memberikan jarak antara isi halaman dengan bagian tepi.
- **Expanded** untuk mengatur penggunaan ruang pada layout.
- **ListView.builder** untuk menampilkan daftar ruangan secara dinamis.

## Refleksi

Widget layout yang paling sulit bagi saya adalah ListView.builder Widget layout yang paling sulit bagi saya adalah ListView.builder karena penggunaannya membutuhkan pemahaman cara menampilkan beberapa data dalam satu halaman. Saya juga perlu memperhatikan penggunaan Expanded agar daftar ruangan dapat ditampilkan tanpa menyebabkan tampilan melebihi ukuran layar. Dari tugas ini saya menjadi lebih memahami cara menggabungkan beberapa widget layout dalam satu halaman Flutter.
