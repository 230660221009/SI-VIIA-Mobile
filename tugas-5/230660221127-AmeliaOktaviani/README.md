## Deskripsi Tugas

Tugas ini mengembangkan prototipe antarmuka pengguna untuk aplikasi mobile pengelolaan penjualan warung. Aplikasi dirancang untuk membantu pemilik warung melihat daftar barang, harga, jumlah stok, dan status ketersediaan barang. Prototipe mencakup dokumen arsitektur informasi, wireframe, implementasi halaman utama menggunakan Flutter, catatan keputusan UI/UX, dan screenshot hasil aplikasi.

## Batasan Prototipe

Data barang masih menggunakan data contoh yang ditulis langsung dalam kode. Prototipe belum terhubung dengan basis data dan belum menyimpan transaksi penjualan secara nyata. Tombol Tambah Transaksi saat ini hanya menampilkan pesan umpan balik.

## Refleksi

Bagian tersulit dalam pengerjaan tugas ini adalah menjaga kesesuaian antara kebutuhan pengguna, rancangan wireframe, dan implementasi Flutter. Tantangan berikutnya adalah menyajikan informasi stok dengan jelas melalui hierarki teks, status warna, dan susunan kartu barang. Saya mengatasinya dengan memeriksa kembali kebutuhan F-03, menggunakan komponen Flutter yang konsisten, dan mencatat alasan setiap keputusan UI/UX.
