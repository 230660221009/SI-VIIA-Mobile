\## Deskripsi Tugas



Tugas ini berisi penyusunan information architecture, wireframe, implementasi halaman utama Flutter, dan catatan keputusan desain UI untuk aplikasi SiRuang Kampus. Aplikasi dirancang untuk membantu mahasiswa melihat daftar serta status ketersediaan ruangan dan menemukan aksi utama pengajuan peminjaman ruang kelas.



\## Daftar File



\- `information-architecture.md` — inventaris layar, pemetaan kebutuhan, dan diagram information architecture.

\- `wireframe.png` — rancangan low-fidelity halaman daftar ruangan dan halaman status peminjaman.

\- `halaman-utama.dart` — implementasi halaman utama SiRuang Kampus menggunakan Flutter.

\- `screenshot-halaman.png` — tangkapan layar hasil tampilan halaman utama.

\- `catatan-keputusan-ui.md` — dokumentasi keputusan desain antarmuka dan alasannya.



\## Refleksi



Bagian tersulit adalah menjaga konsistensi antara wireframe dan kode Flutter karena susunan elemen harus tetap sesuai dengan rancangan awal. Saya juga perlu memastikan warna status, hierarki teks, dan tombol utama mudah dipahami oleh pengguna. Proses ini membantu saya memahami bahwa rancangan antarmuka harus memperhatikan kebutuhan fungsional dan kenyamanan pengguna.
