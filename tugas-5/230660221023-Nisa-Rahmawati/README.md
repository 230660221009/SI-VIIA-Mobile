# Tugas 5 — Prototype UI/UX Perpustakaan Kampus

## Deskripsi

Tugas ini merupakan prototype UI/UX aplikasi Perpustakaan Kampus. Aplikasi dirancang untuk membantu mahasiswa melihat daftar buku, mengetahui status ketersediaan, dan memahami informasi buku sebelum melakukan peminjaman.

## Berkas Tugas

1. `information-architecture.md` — menjelaskan struktur dan hubungan antarlayar.
2. `wireframe.png` — rancangan visual katalog buku dan detail buku.
3. `halaman-utama.dart` — kode implementasi antarmuka Flutter.
4. `screenshot-halaman.png` — tangkapan layar hasil aplikasi.
5. `catatan-keputusan-ui.md` — dokumentasi keputusan desain antarmuka.

## Refleksi

Bagian yang paling sulit adalah menyesuaikan tampilan Flutter dengan rancangan wireframe. Saya perlu memperhatikan susunan kartu buku, ukuran teks, dan tampilan status agar informasi mudah dibaca. Saya belajar bahwa rancangan, implementasi kode, dan catatan keputusan UI/UX harus saling konsisten.

## Deklarasi Penggunaan AI

ChatGPT digunakan sebagai asisten pembelajaran untuk membantu memahami langkah pengerjaan dan memeriksa implementasi antarmuka. Keputusan akhir dan pemeriksaan hasil dilakukan oleh penulis.
