## Deskripsi
Tugas ini membahas analisis kebutuhan dan perancangan user flow untuk aplikasi **Perpustakaan Kampus**.

Aplikasi dirancang untuk membantu mahasiswa dalam mencari buku, melihat ketersediaan buku, mengajukan peminjaman, dan melihat status peminjaman. Petugas perpustakaan dapat mengelola data buku dan memproses pengajuan peminjaman mahasiswa.

## Isi Tugas
Dokumen pada folder ini terdiri dari:
* `dokumen-kebutuhan.md` — berisi deskripsi aplikasi, user persona, kebutuhan fungsional dan nonfungsional, prioritas MoSCoW, user flow, pemetaan kebutuhan ke antarmuka, deklarasi penggunaan AI, dan refleksi.
* `user-flow.png` — diagram user flow utama aplikasi Perpustakaan Kampus.

## User Flow Utama
User flow menggambarkan proses mahasiswa mulai dari membuka aplikasi, mencari buku, melihat detail dan ketersediaan buku, mengajukan peminjaman, hingga mendapatkan status peminjaman.

Alur juga memiliki kondisi ketika buku tidak tersedia dan ketika data peminjaman tidak valid.
