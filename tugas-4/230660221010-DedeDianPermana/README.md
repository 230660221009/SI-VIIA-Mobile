## Nama Aplikasi

**SiRuang Kampus — Sistem Informasi Peminjaman Ruang Kelas**

## Deskripsi Singkat

Pada Tugas 4 ini saya menyusun dokumen analisis kebutuhan dan user flow untuk aplikasi SiRuang Kampus yang berada pada domain peminjaman ruang kelas. Dokumen ini mencakup deskripsi aplikasi, dua user persona, kebutuhan fungsional dan nonfungsional, prioritas fitur menggunakan metode MoSCoW, serta pemetaan kebutuhan ke antarmuka. User flow menggambarkan proses mahasiswa mulai dari memilih ruangan, memeriksa ketersediaan, mengisi formulir, hingga permohonan peminjaman berhasil tercatat dan menunggu pemeriksaan petugas. Rancangan ini menjadi acuan awal untuk pengembangan antarmuka aplikasi pada tugas berikutnya.

## Refleksi

Bagian yang paling sulit bagi saya adalah menentukan prioritas fitur karena mahasiswa dan petugas memiliki kebutuhan yang berbeda, tetapi saling berkaitan dalam proses peminjaman ruangan. Saya menetapkan fitur melihat daftar ruangan, mengajukan permohonan, melihat permohonan masuk, memeriksa benturan jadwal, dan menyetujui permohonan sebagai prioritas utama karena mendukung proses inti peminjaman. Dari tugas ini saya belajar bahwa kebutuhan fungsional, prioritas fitur, dan user flow harus saling konsisten agar rancangan aplikasi sesuai dengan tujuan pengguna dan dapat dikembangkan secara bertahap.
