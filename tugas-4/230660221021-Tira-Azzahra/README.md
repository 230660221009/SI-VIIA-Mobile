## Refleksi (3 kalimat)
Bagian tersulit bagi saya adalah merumuskan kebutuhan fungsional agar tidak terlalu umum dan tetap mengikuti pola aktor–aksi–hasil. Saya juga perlu beberapa kali memperbaiki prioritas MoSCoW supaya jumlah Must have tidak melebihi batas dan tetap sesuai tujuan persona utama. Selain itu, menggambar user flow lengkap dengan dua keputusan dan cabang gagal membutuhkan ketelitian agar alur tidak buntu.
