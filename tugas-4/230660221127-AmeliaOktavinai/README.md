## Deskripsi Singkat
Tugas ini berisi dokumen analisis kebutuhan untuk Aplikasi Mobile Pengelolaan Penjualan Warung. Dokumen memuat penyusunan 2 user persona, pendaftaran kebutuhan fungsional dan nonfungsional yang terukur, pengelompokan prioritas fitur menggunakan metode MoSCoW, perancangan diagram user flow alur transaksi utama, serta pemetaan kebutuhan ke komponen antarmuka widget Flutter.

## Refleksi Penulisan Analisis
Bagian analisis yang paling sulit saya tetapkan adalah perancangan diagram **User Flow**. Hal ini sulit karena saya harus merancang alur transaksi sesederhana mungkin agar pemilik warung dapat mencatat penjualan dengan cepat tanpa kebingungan. Selain itu, saya juga harus memastikan setiap titik keputusan memiliki penanganan cabang kondisi gagal yang jelas ketika stok barang ternyata tidak mencukupi.
