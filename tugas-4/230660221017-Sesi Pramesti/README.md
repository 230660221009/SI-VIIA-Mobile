## Deskripsi Aplikasi
SI-FASKAM (Sistem Informasi Pengaduan Fasilitas Kampus) merupakan rancangan aplikasi yang bertujuan untuk memudahkan mahasiswa dalam menyampaikan pengaduan terkait fasilitas kampus. Melalui aplikasi ini, mahasiswa dapat melihat alur pengaduan, mengisi informasi kerusakan, dan memantau status pengaduan.

## Tujuan Tugas
Tugas ini bertujuan untuk merancang User Flow sebagai gambaran alur interaksi pengguna ketika menggunakan aplikasi SI-FASKAM, mulai dari membuka aplikasi hingga menyelesaikan proses pengaduan fasilitas kampus.

## Alur Pengguna
1. Pengguna membuka aplikasi SI-FASKAM.
2. Pengguna melihat halaman utama aplikasi.
3. Pengguna memilih menu pengaduan fasilitas.
4. Pengguna mengisi informasi pengaduan.
5. Pengguna mengirimkan pengaduan.
6. Sistem menampilkan konfirmasi bahwa pengaduan telah dikirim.
7. Pengguna melihat status pengaduan.
